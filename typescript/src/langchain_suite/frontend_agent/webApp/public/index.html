Welcome to the LangGraph Frontend Agent Demo

This full-stack application demonstrates how to integrate a cyclical LangGraph agent with a modern web UI using two real-world patterns:

Pattern A: In-Process Monolith

The agent graph compiles and executes in the same Node.js process as the web server, streaming SSE lifecycle events straight to your browser.

Pattern B: Decoupled Microservice

The agent runs in a dedicated microservice process (TypeScript on port 4000 or Python FastAPI on port 8000), decoupling heavy agent workloads from web routing.
